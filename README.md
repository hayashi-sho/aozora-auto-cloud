# AOZORA. Auto Cloud v1.9 PRO12

GitHub Pages用の静的Webアプリ。既存v1.8のファイルにpro12.jsを追加。

## 追加した12機能
修理方法比較、塗装原価、骨格寸法記録、損傷写真の手動マーキング、工程工数予測、見積漏れ点検、塗装トラブル候補、写真報告書、作業時間実績、損益分岐点、発注前チェック、品質チェック。

無料のルールベース計算・入力補助であり、外部AIの自動画像判定やメーカー純正データ取得ではありません。車検証OCRは再導入していません。

## 更新
ZIPを展開し中身のファイルをGitHubリポジトリのルートにアップロードしてください。**削除しない既存のデータは端末ブラウザに残ります**が、更新前にアプリの設定画面からJSONバックアップを取ってください。別端末同期はありません。

## 注意
- 既存の主要データは localStorage、板金資料は IndexedDB、PRO12の記録は別の localStorage キーに保存します。ブラウザのデータ削除で失われる可能性があります。
- 写真報告書は印刷・PDF保存が可能。損傷写真そのものは保存せず、マーキング数のみ記録します。
- 利益計算・工程予測は参考値。安全・メーカー修理基準・適合確認を優先。
- 検証は構文・静的統合・計算関数・ZIP整合性まで。実機iPhone/PCブラウザ操作は未検証。
