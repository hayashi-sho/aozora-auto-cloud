# AOZORA. Auto Cloud v2.3 VIN AUTO

GitHub Pages に全ファイルをアップロード。iPhone/PC対応。

## 新機能
- 17桁VINをNHTSA vPIC公式APIで解析（対応車両のみ、ネット接続必須）
- 入力後0.75秒で自動照会、手動ボタンも利用可能
- 登録済みの正規展開図URLをVINまたはメーカー＋車種で自動照合
- 画像URLはプレビュー、資料リンクを表示、見積に追加
- API失敗・日本式短縮車台番号ではローカル照合のみ

## 制限
NHTSAは純正品番や展開図を提供しません。外部有料カタログのスクレイピングは行いません。VINを照会すると米国NHTSAへ送信されます。ブラウザのCORS制限や通信障害によりAPI利用できない場合があります。

## 既存データ
同じGitHub Pages URLなら既存localStorageを継続使用。更新前にアプリ内でバックアップを保存してください。
