# AOZORA. Auto Cloud v1.5

GitHub Pages対応のiPhone向けローカル保存型試作アプリ。AI機能はありません。

## 品質改善
- 未使用部品の引当解除を追加（引当解除後に返品可能）
- CSV出力時の表計算ソフト数式注入対策
- PWAのキャッシュ更新と失敗応答のキャッシュ防止
- 統合バックアップの版数更新

## 注意
データはブラウザのlocalStorageに保存されます。更新前に連動画面からJSONバックアップを取得してください。
実機テスト、税務・法令要件、移行互換性、正式な請求書書式は未検証です。
